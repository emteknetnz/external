# Early ideas

This repo is for sharing early-stage ideas with others. Everything here is probably a
draft, probably incomplete and likely to change. None of it should be considered final,
and it does not reflect any settled position or decision.

Browse the pages at <https://emteknetnz.github.io/external/>.

The index page is generated on each deploy from `index.template` and lists every `.html`
file in the repo. Any `index.html` committed to the repo root is ignored and replaced by
the generated one.
